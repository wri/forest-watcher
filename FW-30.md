# FW-30: iOS App Store — 2026 OS Update

## Description

The 2026 OS update is mandatory and must be completed to ensure Forest Watcher remains available and compliant on the Apple App Store.

## What's Required (Apple App Store)

- Rebuild app using the iOS 26 & iPadOS 26 SDK or later
- Update APNs Trust Store to include the new USERTrust RSA SHA-2 certificate
- Replace any deprecated APIs flagged by Xcode
- Add approved reasons for any required-reason APIs used (including third-party SDKs)
- Complete Age Rating questionnaire update in App Store Connect
- Test via TestFlight before submitting

## Acceptance Criteria

- [ ] App successfully builds with iOS 26 & iPadOS 26 SDK (currently blocked at simulator link time in legacy `Mapbox.framework`)
- [ ] App passes App Store review with no SDK-related rejections
- [ ] All deprecated API warnings resolved (AddressBook removed; remaining triage pending build unblock)
- [ ] TestFlight build tested and approved prior to submission
- [ ] Submitted to App Store by the agreed deadline

## Progress Snapshot (2026-06-24)

- Xcode 26 CLI build pipeline is active and running against iOS 26.5 SDK.
- `AddressBook.framework` was removed from `ios/ForestWatcher.xcodeproj/project.pbxproj`.
- `ios/Podfile` was updated for iOS 16.0 target and Xcode 26 compatibility patches.
- Multiple Xcode 26 compile blockers were resolved (private header import, fmt consteval, module name and framework/header search path issues).
- `react-native-navigation` 8.3.2 was patched for the old-architecture RN 0.79 path, and `ios/ForestWatcher/AppDelegate.mm` now bootstraps through an explicit `RCTBridge`.
- Current simulator blocker is `ld: building for 'iOS-simulator', but linking in dylib .../Mapbox.framework/Mapbox built for 'iOS'`.

## Current Blocker

- The current active build blocker has moved past `react-native-navigation` compile errors and is now the legacy Mapbox simulator binary:
	- `ld: building for 'iOS-simulator', but linking in dylib .../Mapbox.framework/Mapbox built for 'iOS'`
- This blocks arm64 simulator execution, so full FW-30 test-matrix work and TestFlight validation remain blocked.
